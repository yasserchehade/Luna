# Principles

1. Zero manual data entry where possible.
2. Human approval before financial actions.
3. AI should be proactive, not only reactive.
4. Every document should have a single source of truth.
5. Luna should integrate with existing tools rather than replace them.
6. Security is mandatory from day one.
7. The system should be modular and scalable.
8. The MVP must remain simple and usable.

## Product Posture

Luna should reduce administrative load without hiding important decisions from the user. It can extract, classify, suggest, remind, and prepare actions, but payment, filing, or irreversible financial actions require explicit human approval.
