# Domain docs

Luna uses a single-context domain model.

Before exploring or changing the project:

- Read the root `CONTEXT.md`.
- Read relevant decisions under `docs/adr/`.
- Use the glossary's preferred terminology in code, tests, specifications and tickets.
- Explicitly identify any proposed change that conflicts with an ADR.
- If a required concept is absent, record the gap for `domain-modeling` rather than silently inventing competing terminology.
